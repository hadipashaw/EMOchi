# 🤖 EMOchi

**ربات چهره‌ی احساسی مبتنی بر Arduino Uno و نمایشگر OLED 128×64 SSD1306**

EMOchi یک پروژه متن‌باز است که با استفاده از آردوینو و نمایشگر OLED، یک چهره‌ی متحرک با چشم‌های طبیعی و حالات احساسی ایجاد می‌کند.

---

# ✨ قابلیت‌ها

- 👀 حرکت طبیعی چشم‌ها
- 😉 پلک زدن تصادفی
- 😊 حالت خوشحال
- 😠 حالت عصبانی
- 🌙 خواب خودکار در تاریکی
- ☀️ بیدار شدن با بازگشت نور
- 👆 تعامل با سنسور لمس
- 💡 تشخیص نور محیط با LDR
- ⚡ بهینه‌شده برای Arduino Uno
- 🧠 مصرف کم حافظه و پردازنده

| OLED | Arduino |
|------|----------|
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

پایه‌های سنسورها مطابق فایل برنامه قابل تغییر هستند.

---

# 🚀 راه‌اندازی

ابتدا پروژه را دریافت کنید.

```bash
git clone https://github.com/hadipashaw/EMOchi.git
```

سپس فایل زیر را در Arduino IDE باز کنید.

```
Arduino_Code/OLED_Emotion_Robot.ino
```

کتابخانه‌های زیر را نصب کنید.

- Adafruit GFX
- Adafruit SSD1306
- FluxGarage RoboEyes

در نهایت برنامه را روی Arduino Uno آپلود کنید.
